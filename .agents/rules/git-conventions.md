# Git Commit Conventions

When working in this repository, you **MUST** follow these rules:

1. **Commit Frequently**: Make a git commit after completing every discrete change or milestone. Do not leave uncommitted changes hanging.
2. **Conventional Commits with Emojis**: You must format all commit messages using the Conventional Commits specification AND prepend an appropriate emoji.
   - `✨ feat:` for new features
   - `🐛 fix:` for bug fixes
   - `🔧 chore:` for maintenance, dependencies, or minor config changes
   - `♻️ refactor:` for code restructuring without changing behavior
   - `📝 docs:` for documentation updates
   - `✅ test:` for adding or updating tests
   - `💄 style:` for formatting, missing semi-colons, etc.

Example: `✨ feat: implement user authentication via Supabase`
